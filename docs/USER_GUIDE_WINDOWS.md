## 系统简介

### 什么是 BidCheck？

BidCheck 是一个**围标检测系统**，用于分析投标文件，检测不同投标方的文件是否可能来自同一来源。

### 主要功能

- 📄 支持 Word 文档 (.docx)
- 📊 支持 Excel 表格 (.xlsx)
- 📑 支持 PDF 文件 (.pdf)
- 🔍 自动检测可疑痕迹
- 📈 生成风险评分报告
- 🌐 提供 Web 操作界面

### 检测原理

系统会分析文件中的隐藏信息，例如：
- 文档作者信息
- 创建和修改时间
- 编辑会话标识 (RSID)
- 样式指纹
- 嵌入图片哈希
- 等等...

如果两个不同投标方的文件存在大量相同的隐藏信息，系统会给出高风险评分。

## 环境准备

### 2.1 检查 Windows 版本

本系统支持 **Windows 10** 和 **Windows 11**（64位）。

检查方法：
1. 右键点击"此电脑"或"我的电脑"
2. 选择"属性"
3. 查看 Windows 版本和系统类型（应为 64 位）

### 2.2 安装 Python

#### 步骤 1：下载 Python

1. 打开浏览器，访问：https://www.python.org/downloads/
2. 点击下载 **Python 3.11** 或更高版本
3. 等待下载完成

#### 步骤 2：安装 Python

1. 双击下载的安装文件（如 `python-3.11.x-amd64.exe`）
2. **重要**：勾选底部的 **"Add Python to PATH"** 选项
   ```
   ☑ Add Python 3.11 to PATH
   ```
3. 点击 **"Install Now"**
4. 等待安装完成
5. 点击 **"Close"** 关闭安装程序

#### 步骤 3：验证安装

1. 按 `Win + R` 打开运行窗口
2. 输入 `cmd` 并按回车，打开命令提示符
3. 输入以下命令并按回车：
   ```
   python --version
   ```
4. 如果显示 `Python 3.11.x`，说明安装成功

### 2.3 安装 Node.js（用于构建前端）

#### 步骤 1：下载 Node.js

1. 访问：https://nodejs.org/
2. 下载 **LTS 版本**（长期支持版）
3. 双击安装文件，一路点击"下一步"完成安装

#### 步骤 2：验证安装

在命令提示符中输入：
```
node --version
```
如果显示版本号（如 `v20.10.0`），说明安装成功。

## 下载项目

### 方法一：下载 ZIP 压缩包（推荐小白用户）

1. 打开浏览器，访问项目地址：
   ```
   https://github.com/RyneHuang/BidCheck
   ```

2. 点击绿色的 **"Code"** 按钮

3. 选择 **"Download ZIP"**

4. 下载完成后，右键解压 ZIP 文件

5. 将解压后的文件夹移动到一个简单的路径，例如：
   ```
   C:\BidCheck
   ```

### 方法二：使用 Git（适合有经验的用户）

```batch
cd C:\
git clone https://github.com/RyneHuang/BidCheck.git
cd BidCheck
```

## 打包步骤

### 4.1 打开命令提示符

1. 按 `Win + R` 打开运行窗口
2. 输入 `cmd` 并按回车

### 4.2 进入项目目录

在命令提示符中输入：
```batch
cd C:\BidCheck
```
（请将 `C:\BidCheck` 替换为您实际的项目路径）

### 4.3 构建前端界面

**这一步必须先完成！**

```batch
cd web
npm install
npm run build
cd ..
```

等待命令执行完成，看到类似输出说明成功：
```
✓ built in 5.23s
```

### 4.4 运行打包脚本

```batch
scripts\build.bat
```

### 4.5 按提示操作

1. 脚本会自动检查环境
2. 当提示选择打包模式时：
   - 输入 `1` 选择 **GUI 版本**（推荐，有图形界面）
   - 输入 `2` 选择命令行版本

3. 等待打包完成（可能需要几分钟）

### 4.6 获取可执行文件

打包完成后，可执行文件位于：
```
C:\BidCheck\dist\BidCheck.exe
```

## 使用方法

### 5.1 启动程序

#### GUI 版本

1. 双击 `BidCheck.exe`
2. 稍等片刻，会弹出程序窗口
3. 点击 **"启动检测系统"** 按钮
4. 浏览器会自动打开操作界面

#### 命令行版本

1. 打开命令提示符
2. 输入：
   ```batch
   BidCheck.exe serve
   ```
3. 打开浏览器，访问 `http://127.0.0.1:8000`

### 5.2 使用 Web 界面

#### 步骤 1：输入项目信息

在首页输入**项目名称**，例如：`某市政道路工程`

#### 步骤 2：添加投标方

1. 输入投标方名称（如：投标方A、投标方B）
2. 点击 **"上传文件"** 按钮
3. 选择该投标方的投标文件（支持 .docx、.xlsx、.pdf）
4. 可以添加更多投标方

#### 步骤 3：开始分析

点击 **"开始分析"** 按钮，系统会自动：
1. 提取每个文件的元数据
2. 比对不同投标方
3. 计算风险评分

#### 步骤 4：查看结果

分析完成后，会显示：
- **风险评分**：0-100 分，分数越高风险越大
- **风险等级**：
  - 🟢 低风险 (0-30)
  - 🔵 中风险 (31-60)
  - 🟠 高风险 (61-80)
  - 🔴 极高风险 (81-100)
- **可疑痕迹**：列出检测到的所有可疑点

#### 步骤 5：导出报告

点击右上角的导出按钮：
- **HTML**：网页格式报告，可用浏览器打开
- **JSON**：数据格式，便于程序处理

### 5.3 使用命令行

```batch
# 显示帮助
BidCheck.exe --help

# 分析文件
BidCheck.exe analyze "项目名称" "投标方A" "C:\投标文件\A" "投标方B" "C:\投标文件\B"

# 启动 Web 服务
BidCheck.exe serve --port 8080
```

## 常见问题

### Q1: 双击 BidCheck.exe 没有反应？

**可能原因**：
- 杀毒软件拦截

**解决方法**：
1. 检查杀毒软件通知
2. 将 `BidCheck.exe` 添加到白名单
3. 或暂时关闭杀毒软件后再运行

### Q2: 提示"缺少 VCRUNTIME140.dll"？

**解决方法**：
1. 下载并安装 Visual C++ 运行库：
   https://aka.ms/vs/17/release/vc_redist.x64.exe
2. 安装后重启电脑
3. 再次运行程序

### Q3: 程序启动很慢？

**原因**：PyInstaller 打包的程序首次启动需要解压临时文件。

**解决方法**：耐心等待 10-30 秒，后续启动会更快。

### Q4: 浏览器没有自动打开？

**解决方法**：
1. 手动打开浏览器
2. 在地址栏输入：`http://127.0.0.1:8000`

### Q5: 上传文件后没有反应？

**可能原因**：
- 文件格式不支持
- 文件损坏

**解决方法**：
1. 确认文件格式是 .docx、.xlsx 或 .pdf
2. 尝试用 Office 打开文件确认是否正常

### Q6: 如何更新程序？

1. 重新下载最新版本的项目
2. 重新执行打包步骤
3. 替换旧的 `BidCheck.exe`

### Q7: 可以在其他电脑上使用吗？

可以！`BidCheck.exe` 是独立的可执行文件：
1. 将 `BidCheck.exe` 复制到 U 盘
2. 在其他 Windows 电脑上直接运行
3. 无需安装 Python 或其他依赖
