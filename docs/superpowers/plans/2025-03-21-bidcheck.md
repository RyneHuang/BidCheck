# BidCheck 围标检测系统实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 构建一个围标检测工具，通过分析投标文档元数据识别围标风险

**Architecture:** 分层架构 - 提取器层(Extractors) → 分析器层(Analyzers) → 报告层(Report)，通过 CLI/API/Web 三种方式提供服务

**Tech Stack:** Python 3.11+ / FastAPI / python-docx / openpyxl / pypdf / Vue 3 / Element Plus

---
