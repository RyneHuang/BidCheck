                      快速开始指南
══════════════════════════════════════════════════════════════

【第一步】启动程序
  双击 BidCheck.exe 文件

【第二步】点击按钮
  在弹出的窗口中，点击"启动检测系统"按钮

【第三步】打开浏览器
  浏览器会自动打开操作界面（如果没有自动打开，
  请手动访问 http://127.0.0.1:8000）

【第四步】输入信息
  1. 输入项目名称
  2. 添加投标方名称
  3. 上传各投标方的文件（支持 .docx .xlsx .pdf）

【第五步】开始分析
  点击"开始分析"按钮，等待分析完成

【第六步】查看结果
  查看风险评分和可疑痕迹详情

══════════════════════════════════════════════════════════════
                      风险等级说明
══════════════════════════════════════════════════════════════

  🟢 低风险 (0-30分)    - 未发现明显可疑痕迹
  🔵 中风险 (31-60分)   - 存在一些相似之处，需人工核实
  🟠 高风险 (61-80分)   - 发现较多可疑痕迹，建议深入调查
  🔴 极高风险 (81-100分)- 高度怀疑围标，建议进一步取证

══════════════════════════════════════════════════════════════
                      检测项目说明
══════════════════════════════════════════════════════════════

系统会检测以下痕迹类型：

  📝 文档作者        - Word/Excel 的作者信息
  🏢 公司属性        - 文档的公司元数据
  🕐 创建时间        - 文件的创建时间
  🔄 RSID 标识       - Word 编辑会话标识（重要指纹）
  🎨 样式指纹        - 文档样式特征
  🖼️ 嵌入图片        - 相同的嵌入图片
  📊 共享字符串      - Excel 中的相同文本
  📋 模板路径        - 使用的文档模板

══════════════════════════════════════════════════════════════
                      常见问题
══════════════════════════════════════════════════════════════

Q: 双击程序没有反应？
A: 请检查杀毒软件是否拦截，将程序添加到白名单。

Q: 提示缺少 DLL 文件？
A: 请安装 Visual C++ 运行库：
   https://aka.ms/vs/17/release/vc_redist.x64.exe

Q: 程序启动很慢？
A: 首次启动需要 10-30 秒，这是正常的。

Q: 浏览器没有自动打开？
A: 请手动打开浏览器，访问 http://127.0.0.1:8000
